# Project Requirements

## Business Requirements
We want an easy to use calculator that contains basic arithmetic operations.

## User Requirements
- The user will expect a visual button interface to perform addition, subtraction, multiplication, division, and also an equals operand to compute totals.
- The user will be able to compute exponents and mathmatical operations with parenthesises.
- The software should remain visually consistent, no flashing or refreshing upon button press.
- Trigonometry: compute sine, cosine, tangent, and their inverse functions.
- Logarithms: compute ommon logarithms (base 10) and natural logarithms (base e).
- Exponents and roots: calculates squares, cubes, roots, powers (x^y).
- Constants and Pi: include dedicated keys for mathematical constants like π (pi) and e.
- The look and feel needs to be like a normal calculator, numbers on one side. 
- The style is modern and sleek.


## Software Requirements
- Python 3
- Python Flask
- No JavaScript
- HTML/CSS
- Include a .md file that traces your development steps for reproducibility.
